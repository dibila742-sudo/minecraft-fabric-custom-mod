# Custom Mod

Это репозиторий с примером Fabric-мода для Minecraft 1.21.4 с:

- кастомным UI/GUI
- закруглённым интерфейсом без пиксельного вида
- кастомным временем мира
- кастомным фогом
- правым кликом для настроек
- открытием по правому Shift
- закрытием по ESC

## Структура

- `src/main/java/com/example/custommod` — Java-код мода
- `src/main/resources` — ресурсы и `fabric.mod.json`

## Запуск

1. Установите Java 21
2. В корне проекта выполните:

```bash
./gradlew build
```

или откройте проект в IDE и запустите `runClient`.

## Основные функции

- `Right Shift` → открывает меню настроек
- `ПКМ` по пустой руке или в воздухе (если включено) → открывает меню настроек
- `ESC` → закрывает настройки
- Переключатели в окне меняют кастомные параметры фога, времени и поведение мода

## Примечание

Это базовый рабочий каркас для Fabric-мода 1.21.4. Его можно доработать под любой дизайн и логику.
